TRANSORA PROJECT - QUICK START

1. Extract Transora_Project.zip into a folder.
2. Open VS Code.
3. Choose File > Open Folder and select the extracted Transora_Project folder.
4. In the left Explorer, double-click index.html.
5. Right-click index.html and choose "Open with Live Server" if the Live Server extension is installed.
   If not, open the folder in File Explorer and double-click index.html to open it in your browser.
6. Test:
   - See the three sample buses.
   - Add a bus using the Manage bus details form.
   - Change status and save.
   - Remove a bus.
   - Refresh the page; changes should remain in the same browser.
7. Capture screenshots for the report after testing.

IMPORTANT:
- This is a front-end prototype. Data is stored in local browser storage and does not sync to other devices.
- Demo routes/times are sample data. Replace them with approved college details only if permitted.
- Confirm with your faculty that this project and documentation format are acceptable.
